# 出图提示词写法参考

## 1. 六段结构

按顺序写六件事，每段短句即可，不要堆同义词：

1. 主体：年龄/性别/人种、服装、材质（"白色轻薄长裙"比"仙女裙"有效）。
2. 姿态：站位、朝向、手在做什么、视线方向。
3. 环境：地点、前景/背景元素、天气或时间、画面里允许出现的次要物体。
4. 光线：方向（逆光/侧光/顶光）、软硬、色温、是否带光晕或雾。
5. 镜头：焦段（35mm/85mm）、光圈（f/1.8、f/2）、景深、构图（半身/全身/侧身回望）。
6. 质感：皮肤、发丝、织物、对焦位置，再补一句"真实摄影/电影感/高细节"。

中文可直接用，Qwen 系列对中文长句理解稳定；z_image 中英文都可用，句子可以更短。

## 2. 已验证示例

### 2.1 海边美女（Qwen-Image 2.1，2048×2048，约 87 秒）

```
清晨的海边，薄雾弥漫在空气中，一位年轻亚洲女性站在齐踝的浅水里，身穿白色轻薄的长裙，赤脚，
长发和裙摆被海风轻轻吹起，姿态自然放松，侧身微微回望镜头，神情安静柔和；远处海面、礁石和海岸线
在晨霭里一层层淡出，两三只海鸥在她身后低空掠过，最近的一只贴着水面飞行，没有遮住人物；柔和的逆光
穿过雾气形成淡淡的光晕，低对比，空气中有细腻的雾气层次；人物面部、发丝和裙料对焦精准、清晰锐利，
皮肤有真实质感，织物纹理清楚，只有远景因雾气而变淡；真实摄影，85mm 中长焦，f/2 浅景深，柔和高光，
电影感，高细节
```

负向：

```
模糊，失焦，噪点，低清晰度，塑料皮肤，畸形手指，多余肢体，海鸥过多，画面过暗，过曝
```

拆解：主体（亚洲女性/白裙/赤脚）→ 姿态（侧身回望/自然放松）→ 环境（浅水/礁石/海鸥/晨雾）→ 光线（逆光/柔光/低对比）→ 镜头（85mm/f2/浅景深）→ 质感（皮肤/发丝/织物/只有远景变淡）。注意每个元素都带了位置或"不要遮住人物"这类约束，模型才不会把元素堆到脸上。

### 2.2 照片加人（Qwen-Image 2.1 编辑，已验证）

```
在照片中男士的右侧添加一位年轻亚洲女性一起合照，她面向镜头微笑，穿着与场合相符的浅色连衣裙，
身高和透视与男士一致，光照方向、色温、白平衡与原照片完全一致，背景和地面保持原样
```

负向：

```
改变原人物，多余肢体，畸形手指，塑料感，颜色失真，明显拼贴边缘
```

编辑任务的关键是"位置 + 比例 + 光照 + 不许改什么"四件事都写出来。只写"加一个美女"会得到比例不对、光照不匹配的结果。

### 2.3 遮罩重绘加人（z_image，已验证，768×1376，约 21 秒）

```
黄昏海边浅水区合照照片：一位年轻亚洲女性站在男士右侧，穿浅色吊带连衣裙，长发被晚风轻拂，
逆光金色轮廓，与男士同样的夕阳光照和相同的透视距离，赤脚站在浅水中，水面有倒影和涟漪，
背景是城市天际线、晚霞与远处游泳的人群，真实摄影质感，自然融合
```

这里不要写"修复/重绘/遮罩内"之类的词，就按正常出图描述遮罩区域应有的内容。

### 2.4 场景感页面（Qwen-Image 2.1 文生图，1024×1024）

```
雨后的上海街头，霓虹倒映在湿滑的地面上，一位撑透明雨伞的女生走过，电影感，浅景深，高细节，真实摄影
```

短提示词也能出效果，适合先试构图，再逐步加细节。

## 3. 负向提示词

- z_image 文生图工作流用 `ConditioningZeroOut`（空负向），不需要写负向。
- z_image 遮罩重绘同样是 `ConditioningZeroOut`。
- Qwen-Image 2.1 的 `TextEncodeQwenImage21` 有独立 `negative_prompt` 字段，按场景写：人像写"塑料皮肤、畸形手指、多余肢体"，写实场景写"模糊、过曝、颜色失真"。

## 4. 按任务调整

| 情况 | 改什么 |
|---|---|
| 人物脸崩、手崩 | 补"面部对焦精准/手指自然弯曲"，负向加"畸形手指"；仍不行就换 Qwen 编辑并给参考图 |
| 画面太满、元素打架 | 给每个元素加位置约束，删掉不必要的形容词 |
| 想要更"照片" | 加焦段+光圈+"真实摄影"，减少"唯美/梦幻"这类抽象词 |
| 想要更大画幅 | 先 2048×2048 直出，再走超分到 3072；不要直接写 3072 的尺寸 |
| 想复现同一张 | 固定种子，其他参数一律不动 |

## 5. 尺寸与构图

- 宽高都取 16 的倍数：1024×1024、768×1376（竖）、1024×1536（竖）、1536×1024（横）。
- 竖幅超过 1024×1800 易爆显存，宁可先小图再超分。
- Qwen 编辑任务的画幅跟随参考图比例，用 `resolution` 控制归一尺寸（默认 1280）。
